# ADR 0004: 使用真实采集进行标定回归

日期：2026-10-30。状态：依据用户明确指令实施。负责人：SilverWolf。

## 背景与决定

用户要求“别用合成数据，现在已经接到相机”。该要求覆盖原
REQ-CAL-010 的合成自检路径，现将需求同步为真实采集回归。
不通过生成棋盘图像、IMU 数据或求解结果代替真实输入，也不将其用于验收。
格式、数学与通信状态机的单元测试仍可使用常量和测试替身；它们不构成传感器测量证据。

## 实现与运行

`calibration` 的默认 CTest 不再注册渲染棋盘与 `calibrate --self-test`。
历史入口保留，不用于当前验证。`stereo_calibration_real` 通过
`SPR_CALIBRATION_REAL_SESSION` 选择真实 D435i 会话，读取原始派生 PNG、索引与元数据，
在临时目录使用默认门槛求解。回归检查留出误差、两相机覆盖率、
cam0→cam1 变换方向、导出一致性和局部联合协方差，并核对输入文件哈希未变。

未设置输入目录时，CTest 用退出码 77 明确跳过；指定目录缺失或不达标时失败，
不回退到合成数据。CI 应挂载有来源记录的真实采集并设置该变量；
当前仓库尚未完成 CI runner 与数据分发配置，不能把本机通过声明为 CI 已完成。

## 验证边界

本机使用 `runs/20261029T115312_d3a3703b/images/20261029_195318` 的真实
D435i 图像完成回归：110 对输入中 108 对检测成功、87 对拟合、21 对留出，
本次拟合 RMS 约 0.181 px，留出 RMS 约 0.185 px。
数据保持在 Git 外；部署到其他机器时须提供实际归档，不能依赖这个本地路径。

这仅验证相机图像链路，不补齐原始 bag 的时间戳问题，不证明相机—飞控联合标定完成。
静止 Allan、固定标定板并移动相机/飞控组件的联合采集、独立留出和 OpenVINS
实际回放仍为必需。质量门槛、变换/时间符号与 MAVLink 测试范围保持不变。
